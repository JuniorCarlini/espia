# Brand assets

| Path                     | Used for                                                        |
| ------------------------- | ---------------------------------------------------------------- |
| `espia.icon/`             | **macOS app icon** — compiles to a real Liquid Glass icon. See [ADR 0008](../adr/0008-macos-liquid-glass-icon.md). |
| `build-icon.sh`            | Compiles `espia.icon/` into `agent/src-tauri/icons/Assets.car` + `icon.icns` |
| `icon-source.png`          | Source for the remaining plain-PNG icon sizes (Windows `.ico`, and the raw PNGs Tauri's bundler asks for directly) |
| `generate-icon.py`         | Regenerates `icon-source.png`                                    |

`agent/src/assets/wordmark.png` (the header logo, and the icon's glyph
layer) is a separate, tightly cropped asset — see
[`agent/README.md`](../../agent/README.md).

## macOS icon: `espia.icon/`

The real, Liquid-Glass-rendering app icon — see
[ADR 0008](../adr/0008-macos-liquid-glass-icon.md) for why this exists and
how it works. It's a hand-authored [Icon Composer](https://developer.apple.com/icon-composer/)
`.icon` bundle: `icon.json` (background fill + the wordmark as a glyph
layer) plus `Assets/wordmark.png`.

To rebuild after changing it (needs **Xcode**, not just the Command Line
Tools, for `actool`):

```sh
docs/assets/build-icon.sh
```

This writes `agent/src-tauri/icons/Assets.car` and `icon.icns`. Restart
`tauri dev`, or run `tauri build`, to pick up the change — the real
rendering (shadow, glass material) only shows in an actual bundled `.app`;
`tauri dev`'s raw binary won't reflect it.

## `icon-source.png`

1024×1024, a 824×824 superellipse ("squircle") centered in the canvas —
macOS's icon safe-area proportions since Big Sur. Still used for the icon
sizes `espia.icon/` doesn't cover: Windows's `.ico`, and the raw PNGs
Tauri's bundler config lists directly (`32x32.png`, `128x128.png`,
`128x128@2x.png`).

Generated by [`generate-icon.py`](generate-icon.py) from
`agent/src/assets/wordmark.png` and a fitted approximation of the original
background gradient — not hand-designed, so if the brand mark changes, run
that script again rather than editing this file directly:

```sh
python3 docs/assets/generate-icon.py  # needs: pip install pillow numpy
```

Then regenerate the PNG/ICO sizes:

```sh
cd agent
npx tauri icon ../docs/assets/icon-source.png
rm -rf src-tauri/icons/ios src-tauri/icons/android  # not targeting mobile yet
# tauri icon overwrites icon.icns too — restore the Liquid Glass one after:
../docs/assets/build-icon.sh
```
