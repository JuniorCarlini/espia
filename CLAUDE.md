# espia — notes for AI assistants

- This is an open-source project. Everything committed to the repository —
  code, comments, identifiers, docs, commit messages — must be in **English**.
- Follow [CONTRIBUTING.md](CONTRIBUTING.md): Conventional Commits with a body
  that explains why the change exists.
- Protocol changes must update `protocol/README.md` and `protocol/examples/`
  in the same change.
- Significant technical decisions get an ADR in `docs/adr/`.
- Add user-visible changes to `CHANGELOG.md` under "Unreleased".
